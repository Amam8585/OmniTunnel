## Validation

Local environment: Ubuntu 24.04 userspace, GCC 13, Clang 18.1.3, Go 1.26.3.
Both compilers compile/link the full C core with Wall/Wextra/Werror. Validation
includes Go vet/test-race, both-architecture rebuild comparison, Python unit tests,
Bash syntax, ShellCheck error-level analysis, shell regressions and offline benchmarks.
The final CI results belong to the exact PR commit, not the previously merged PR.

Installer integration uses real GCC and real binaries in temporary prefixes;
systemctl is mocked. Cases: fresh activation, artifact tampering, incomplete
manifest, foreign command symlink, active-unit guard, four injected activation
failures, repeated activation, backup, auto/manual rollback, uninstall and keeping
unowned binaries/user files. This is not real systemd/TUN/package-manager validation.

Local ASan/UBSan runs use detect_leaks=0 because the sandbox prevents LeakSanitizer
from reading /proc/PID/task. An enabled attempt failed inside LSan. CI retains
**detect_leaks=1** on Ubuntu 22.04/24.04. No local successful leak check is claimed.

Microbenchmarks are synthetic and do not measure end-to-end throughput, packet
loss, latency or goodput. No 2,000-user test was performed. 2,000 users each actively
sending 10 Mbit/s means about **20 Gbit/s payload**, plus encapsulation overhead.
This is a target, not a demonstrated result.

## Remaining limits

- ICMP remains single-threaded, unauthenticated and unencrypted. Source IP/echo ID
  are not authentication. Its 16-bit resync heuristic cannot distinguish every
  delayed duplicate from a peer restart/flow eviction. Replay-safe redesign needs
  a versioned wire protocol and compatibility testing.
- Queues are bounded by capacity, but high flow-slot settings can consume substantial
  memory. Sustained load, tail latency, memory ceilings and multi-gigabit operation
  are not certified. Changing a queue size does not prove a performance improvement.
- C keyed transports use random 192-bit nonces. This audit is not a cryptographic
  proof or complete replay-protection assessment; vendored Monocypher was built
  and exercised, not independently cryptographically audited.
- WebSocket is a binary tunnel endpoint, not a general-purpose text endpoint. A
  comprehensive close-status/UTF-8 conformance suite remains outside this change.
- ARM64 Go artifacts are cross-compiled/byte-checked, not executed on ARM hardware.
  Bundled historical C binaries are not certified by Go checks; the local installer
  compiles C source. Legacy direct SSH provisioning still needs two-host testing,
  especially mixed architectures and updating running remote installations.
- Legacy controller lifecycle/sourced legacy configuration are not fully migrated;
  legacy root-owned configuration must remain trusted.
- Hard power-loss atomicity, external firewall-manager interaction, full concurrent
  create/delete/reconfigure, long-duration reconnects and network saturation need
  privileged two-host/systemd testing.
- No live server, routes, firewall or deployment was changed. Retired transports
  were not reintroduced to the allowlist.

Do not interpret this PR as proof that all defects are eliminated or that production
installation/20-Gbit/s capacity is certified. Review actual CI and these limits before
an explicitly scheduled deployment.
